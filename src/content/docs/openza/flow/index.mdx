## What you can do

- **Bring agent sessions together.** Browse session history from native Windows and detected WSL distributions in one view.
- **Find the right session.** Search, filter by environment, group by date or repository and folder, and preview recent conversations.
- **Return to the original environment.** Open a supported session in Windows Terminal using its original environment and working directory.
- **See review requests.** View pull requests where someone has requested your review.
- **Follow your pull requests.** See pull requests you created and open them on GitHub.
- **Monitor releases and Actions.** See recent repository releases and GitHub Actions workflow runs.
- **Choose notifications.** Turn on background refresh and Windows notifications if you want them.
